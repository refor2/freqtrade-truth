# Freqtrade Truth v0.1.0 — read-only numerical-candidate audits

This is a universal Python library for operator-controlled Freqtrade and
supported exchange data. It does **not** require access to any maintainer
account or private infrastructure. Each operator configures their own
**Read-only** credentials in their own local environment (never GitHub).

## Included

- GET-only Freqtrade, OKX and Bybit source adapters, bounded source reads
  and explicit native instrument/currency checks.
- Immutable UTC/Decimal trade records and safe numerical reconciliation with
  explicit tolerances, missing-data states and exchange-minus-bot deltas.
- Source-native fee/fill/account-bill and funding *candidate* checks.
- Default-redacted JSON, CSV and static HTML reports and a loopback report API.
- Synthetically tested Python 3.11–3.14 compatibility and wheel/sdist assets.

## Critical limitations

- A numeric `match` **does not** verify ownership of the same trade or full
  financial settlement; account-level verification is out of scope.
- Historical funding attribution, complete event retention and time-specific
  USDC/USD conversion are **not** independently certified.
- No trading operations, real account data, credentials or private operator code
  are present. Financial statements, tax reporting and execution decisions
  must not rely on this candidate-only result as conclusive accounting.

## Upgrade / compatibility

This first 0.1 release fixes the documented candidate-only interface.
Python 3.11 through 3.14 are covered in CI. 0.0.x public previews were not
stable; check the updated status/coverage guidance before consuming reports.
